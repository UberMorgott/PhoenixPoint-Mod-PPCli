[h1]PPCLI[/h1]

[b]PPCLI 不会为游戏添加任何内容。[/b]它是开发工具。它让 AI 智能体和脚本通过命令行完全控制正在运行的 Phoenix Point，用于模组开发和测试。它不适合正常游玩。

[b]问题和建议只在 GitHub Issues 提交：[/b][url=https://github.com/UberMorgott/PhoenixPoint-Mod-PPCli/issues]github.com/UberMorgott/PhoenixPoint-Mod-PPCli/issues[/url]
Steam 评论不用于报告错误或提出请求。

[h2]本物品包含什么[/h2]
[list]
[*]只有 PPBridge，即游戏内的部分。客户端（ppcli.ps1，PowerShell 7）在 GitHub 上。
[*]默认关闭。在本模组文件夹里创建名为 [b]ppcli-enabled[/b] 的空文件之前，它什么也不做。删除该文件即可关闭。
[*]连接使用带随机令牌的本地 Windows 命名管道。不打开任何网络端口。
[*]它可以修改存档。在 Steam 安装的游戏上，除非客户端以 -AllowMutate 运行，否则会拒绝修改游戏的操作。
[/list]

[h2]功能[/h2]
[list]
[*]读取游戏状态：场景、阶段、活动对象句柄。
[*]反射：创建对象，读取和设置字段与属性，调用方法，查看值。
[*]搜索游戏定义，并写出完整的定义目录。
[*]执行控制台命令，读取和设置控制台变量。
[*]读取 Unity 日志，订阅 C# 事件。
[*]等待条件：游戏就绪、阶段、调用结果、日志行、事件、跟踪命中、时间。
[*]在运行时跟踪游戏或模组的任意方法：调用、参数、返回值、调用栈。
[*]跨多帧执行多步计划，支持状态查询、取消和清理步骤。
[*]截图。
[*]战术：列出小队和技能，对单位或位置使用技能，结束回合。
[*]界面：读取 uGUI 树并点击元素；列出并按下其他模组 OnGUI 窗口中的按钮。
[*]快照与恢复；从 *.test.json 文件运行模组测试并输出 JUnit 结果。
[/list]
