[h1]PPCLI[/h1]

[b]PPCLI ничего не добавляет в игру.[/b] Это инструмент разработки. Он позволяет ИИ-агентам и скриптам полностью управлять запущенной Phoenix Point из командной строки, для разработки и тестирования модов. Для обычной игры он не предназначен.

[b]Проблемы и предложения — только в GitHub Issues:[/b] [url=https://github.com/UberMorgott/PhoenixPoint-Mod-PPCli/issues]github.com/UberMorgott/PhoenixPoint-Mod-PPCli/issues[/url]
Комментарии в Steam для сообщений об ошибках и просьб не используются.

[h2]Что в этом предмете[/h2]
[list]
[*]Только PPBridge, часть внутри игры. Клиент (ppcli.ps1, PowerShell 7) лежит на GitHub.
[*]По умолчанию выключен. Ничего не делает, пока вы не создадите пустой файл [b]ppcli-enabled[/b] в папке этого мода. Удалите файл, чтобы выключить.
[*]Связь идёт через локальный именованный канал Windows со случайным токеном. Сетевой порт не открывается.
[*]Может изменить сохранение. На установке из Steam действия, меняющие игру, отклоняются, если клиент запущен без -AllowMutate.
[/list]

[h2]Что он умеет[/h2]
[list]
[*]Читать состояние игры: сцену, фазу, живые хэндлы объектов.
[*]Рефлексия: создавать объекты, читать и менять поля и свойства, вызывать методы, смотреть значения.
[*]Искать дефы игры и записывать полный каталог дефов.
[*]Выполнять консольные команды, читать и менять консольные переменные.
[*]Читать лог Unity и подписываться на события C#.
[*]Ждать условия: готовность игры, фаза, результат вызова, строка лога, событие, срабатывание трейса, время.
[*]Трейсить любой метод игры или мода во время работы: вызовы, аргументы, возвращаемое значение, стек.
[*]Выполнять многошаговые планы через несколько кадров со статусом, отменой и шагами очистки.
[*]Делать скриншоты.
[*]Тактика: список отряда и способностей, применение способности по юниту или точке, конец хода.
[*]UI: читать дерево uGUI и нажимать элементы; находить и нажимать кнопки в окнах OnGUI других модов.
[*]Снимок и восстановление; запуск тестов модов из файлов *.test.json с выводом JUnit.
[/list]
